# Pathology Notes

"Cria uma aplicação web para médicos patologistas em Portugal (idioma: pt-PT). A app deve ter um painel limpo com um botão grande para 'Iniciar Gravação de Voz' (áudio do microfone) e uma área para 'Ficheiros de Áudio' (fazer upload de ficheiros MP3/WAV). O objetivo principal é transcrever relatórios de autópsias e exames histológicos. Inclui um editor de texto onde o resultado transcrito aparece, permitindo que o médico edite manualmente o texto final. Adiciona um botão para 'Exportar como Relatório PDF' estruturado. Usa um design profissional, em tons de azul clínico e branco."
